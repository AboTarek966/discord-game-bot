## التشغيل محليًا

```bash
pip install -r requirements.txt
python main.py
```

## النشر على tech-code.dev

1. أنشئ حسابًا في https://tech-code.dev/register
2. أنشئ خادمًا جديدًا واختر قالب **Python**.
3. ارفع ملفات المشروع عبر مدير الملفات أو SFTP.
4. اضبط متغير البيئة `DISCORD_TOKEN` أو احتفظ بملف `.env`.
5. اجعل أمر التشغيل: `python main.py`
6. اضغط **Start** وراقب السجل.
